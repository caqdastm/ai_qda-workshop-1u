# Codebook

Codebook jest śladem procesu kodowania, nie tylko końcową tabelą.

- `codebook_working.csv` - wersja robocza aktualizowana po etapach.
- `codebook_final.csv` - wersja końcowa.
- `notes.md` - decyzje o zmianach, definicjach, scalaniu i odrzucaniu kodów.
- `versions/` - kopie robocze z ważnych momentów warsztatu.

Każdy zaakceptowany kod powinien mieć powiązanie z etapem, notebookiem, jednostką tekstu, cytatem i notatką audytową.
