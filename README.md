# AI QDA Workshop

Publiczne materiały dla osób uczestniczących w warsztacie jakościowej analizy
danych z AI.

## Zacznij Tutaj

1. Otwórz [`00_github_colab/`](00_github_colab/) i wykonaj moduł wprowadzający.
2. Dane warsztatowe znajdują się w [`01_data/`](01_data/).
3. Pozostałe części będą uzupełniane po zsynchronizowaniu materiałów autorów.
4. Cztery notebooki Vibe Coding są już dostępne bezpośrednio w
   [`04_vibe_coding/`](04_vibe_coding/).

## Struktura

```text
00_github_colab/          wprowadzenie do GitHuba, Colaba i Gemini
01_data/                  dane warsztatowe
02_ai_prompting/          materiały w przygotowaniu
03_ai_assisted_coding/    materiały w przygotowaniu
04_vibe_coding/           cztery notebooki uczestnika
05_ai_programming/        materiały w przygotowaniu
06_outputs/               katalog wyników pracy uczestników
```

Repozytorium zawiera wyłącznie materiały uczestnika. Kod procedur autorskich,
logi modeli, materiały review i pełne zaplecze analityczne nie są tutaj
publikowane.

## Zasady Pracy

- nie nadpisuj danych w `01_data/`;
- nie umieszczaj w Git kluczy API, haseł ani tokenów;
- kod wygenerowany z AI uruchamiaj najpierw na małej próbce i sprawdzaj wynik;
- kontrola techniczna nie zastępuje decyzji badacza o trafności kodowania.
